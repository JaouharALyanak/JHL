# SEO Checklist — JHL.ma Refonte

## Technique

- [ ] Title tag optimisé (50-60 chars)
- [ ] Meta description (150-160 chars)
- [ ] H1 unique par page
- [ ] Hiérarchie Hn respectée (H1 > H2 > H3)
- [ ] Images : alt, width, height, lazy loading
- [ ] Canonical tag présent
- [ ] Schema.org LocalBusiness / ProfessionalService
- [ ] robots.txt présent
- [ ] sitemap.xml généré
- [ ] Redirects 301 si changement d'URLs
- [ ] HTTPS vérifié
- [ ] Pas de contenu dupliqué

## Performance

- [ ] Score Lighthouse Performance > 90
- [ ] LCP < 2.5s
- [ ] CLS < 0.1
- [ ] FID < 100ms
- [ ] Images WebP ou SVG
- [ ] CSS/JS minifiés
- [ ] Fonts preload

## Contenu

- [ ] Textes originaux (0% duplicate)
- [ ] Densité mots-clés naturelle
- [ ] Mots-clés principaux dans H1, H2
- [ ] Contenu > 300 mots par section
- [ ] Liens internes entre sections
- [ ] Appels à l'action clairs

## Open Graph & Social

- [ ] og:title
- [ ] og:description
- [ ] og:image (1200x630px)
- [ ] og:url
- [ ] og:type
- [ ] og:locale
- [ ] Twitter Card

## Accessibilité

- [ ] Attributs aria-label sur sections
- [ ] Contraste couleurs suffisant
- [ ] Navigation au clavier fonctionnelle
- [ ] Textes alternatifs pertinents
- [ ] Focus visible
